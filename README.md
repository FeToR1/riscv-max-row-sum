# RISC-V asm 

Найти строку с максимальной суммой элементов в матрице 6 × 6.

**Реализация.** [main.s](main.s) — программа на ассемблере для Venus;
[main.c](main.c) — самостоятельная реализация на C. Обработка матрицы
в обеих программах вынесена в функцию `max_sum_row`.

Для каждой строки вычисляется сумма, затем выбирается наибольшая.
Начальный максимум берётся из первой строки, поэтому отрицательные суммы
обрабатываются корректно. При равенстве выбирается первая строка.
Индексы начинаются с нуля.

В ассемблере `a0` передаёт адрес матрицы, `a1` — число строк,
`a2` — число столбцов; результат возвращается в `a0`.
Используются временные регистры `t0–t6`, возврат выполняется через `ra`.
В C порядок аргументов: число строк, число столбцов, матрица.

**Сборка C для RISC-V.** Из папки проекта:

```powershell
docker build --platform linux/amd64 -t riscv-lab .
docker run --rm --mount "type=bind,source=$($PWD.Path),target=/work" riscv-lab sh build.sh
```

[build.sh](build.sh) использует GCC с `-march=rv32i -mabi=ilp32`.
Результаты: `build/main.elf`, [полный дамп objdump -D](build/main.dump)
и [ассемблер от компилятора](build/main.compiler.s).
ELF используется для дампа; системные вызовы ввода-вывода заменены заглушками `nosys`.

**Сравнение.** Ручной ассемблер хранит счётчики и суммы в регистрах
и обходит строку с шагом 4 байта. GCC без оптимизации использует стек
и вызывает `__mulsi3` для вычисления адреса строки, поскольку RV32I
не содержит инструкции умножения. Обе реализации выбирают одинаковую строку.
